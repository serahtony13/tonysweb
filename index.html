Interface parts the browser ships with

Each of these used to need a library. Now it's a few lines of HTML or CSS, with keyboard support and screen reader roles included.

Dialog and popover

A <dialog> traps focus, closes with Esc and makes the page behind it inert. A popover opens and dismisses without any script.

Click anywhere else, or press Esc, to close this.

Questions

Do I need JavaScript?

Popovers and these accordions work with HTML alone. Opening a dialog takes one line of script.

Will it run on GitHub Pages?

Yes. It's a single static file, so save it as index.html in your repository and turn on Pages.

Is it accessible?

Native controls come with keyboard handling, focus states and correct roles. This page also respects your dark mode and reduced motion settings.

Form checks without a library

The browser validates the address and only shows an error after you've typed something wrong.

Enter an address like name@example.com.

A card that responds to its own width

Drag the bottom-right corner of the dashed box. The layout changes because of a container query, not the screen size.

Resize me

Narrow, the icon sits above the text. Wide, it moves to the side and the heading grows.

Colour that stays in tune

Every colour on this page comes from one hue value using oklch(). Shades are mixed with color-mix(), so moving the colour slider above updates all of them together.
